🎯 ARCHITECTURE CLÉS

1. RÔLES CONTEXTUELS (INNOVATION CLÉE)
   ❌ Mauvais  : User.role = "bailleur"
   ✅ Xwétô   : EntityRole(user_id, entity_type, entity_id, role_type)
   → Alice = BAILLEUR sur maison X, LOCATAIRE sur unité Y

2. SNAPSHOTS LEASE (INTÉGRITÉ)
   ❌ Mauvais  : Lease→unit_id→unit.rent_amount (référence)
   ✅ Xwétô   : Lease.rent_amount = copie au moment du bail
   → Augmenter loyer unité ≠ change les bails signés

3. VALIDATION CROISÉE (TRANSPARENCE)
   ✅ Xwétô   : CHECK validated_by_user_id ≠ submitted_by_user_id
   → Aucun ne peut valider sa propre saisie

4. INDEXES PARTIELS (UX)
   ✅ Xwétô   : UNIQUE (unit_id) WHERE status = 'actif'
   → Une unité = plusieurs bails, un seul ACTIF

5. ENUMS FLEXIBLES (MIGRATION)
   ✅ Xwétô   : VARCHAR(40) au lieu d'ENUM natif PG
   → Ajouter une valeur d'enum = migration simple

🚀 DÉMARRAGE RAPIDE

1. Générer migrations
   $ cd xwhetô_Backend

   $ alembic upgrade head

2. Lancer les tests
   $ pytest tests/test_models_basic.py -v

   $ PGPASSWORD='xweto' psql -U xweto -d xweto_db -c '\dt'
